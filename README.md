# 🚀 Trilha de Estudos: Backend com Java

Bem-vindo ao meu repositório de estudos em **Java**! Este espaço é dedicado à minha jornada de evolução no desenvolvimento backend, partindo dos fundamentos da lógica de programação até a construção de aplicações robustas com **Spring Boot**.

O objetivo aqui é documentar meu aprendizado, armazenar exercícios práticos, códigos limpos e projetos que demonstram a minha evolução técnica.

---

## 🗺️ Roadmap de Aprendizado

Abaixo está o planejamento da trilha que estou percorrendo:

- [x] **Módulo 1: Lógica de Programação e Fundamentos**
    - Variáveis, Tipos de Dados e Operadores
    - Estruturas de Condição (`if/else`, `switch`)
    - Estruturas de Repetição (`for`, `while`, `do-while`)
    - Arrays e Matrizes
- [x] **Módulo 2: Programação Orientada a Objetos (POO)**
    - Classes, Atributos e Métodos
    - Pilares da POO (Encapsulamento, Herança, Polimorfismo e Abstração)
    - Classes Abstratas e Interfaces
    - Tratamento de Exceções (`try-catch`)
- [x] **Módulo 3: Java Avançado e Collections Framework**
    - List, Set, Map (`ArrayList`, `HashSet`, `HashMap`)
    - Streams API e Expressões Lambda
    - Manipulação de Datas (`java.time`)
    - Programação Funcional básica
- [ ] **Módulo 4: Banco de Dados e Persistência**
    - Modelagem Relacional (SQL básico)
    - Conexão Java com Banco de Dados (JDBC / JPA)
- [ ] **Módulo 5: Ecossistema Spring & Spring Boot**
    - Introdução ao Spring Framework e Injeção de Dependências
    - Criação de APIs REST com Spring Boot
    - Spring Data JPA e Hibernate
    - Documentação, Testes e Boas Práticas
